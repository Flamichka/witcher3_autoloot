# Witcher 3 AutoLoot

![REDkit 5.0.1044630](https://img.shields.io/badge/REDkit-5.0.1044630-CD2027)
![Game build 5.0.0.1044392](https://img.shields.io/badge/Game_build-5.0.0.1044392-457B9D)

An auto-loot mod for The Witcher 3 Remastered. Walk near a chest, corpse, loot bag or herb and its available loot is transferred to Geralt's inventory automatically.

The collection radius defaults to 3 metres. In **Settings → Mods → AutoLoot**, you can change it from 1 to 6 metres or turn auto-looting off.

Locked and disabled containers are skipped. Collected items use the game's normal inventory transfer and container-emptying logic.

## Installation

Close the game and copy the `Mods` and `bin` folders into your The Witcher 3 installation folder. Replace the mod's files if updating.

If `dx11filelist.txt` and `dx12filelist.txt` exist in `bin/config/r4game/user_config_matrix/pc`, add `modAutoLoot3mRemastered.xml;` to each on a new line.

Launch the game. Settings are under **Settings → Mods → AutoLoot**.
