# AutoLoot — настройки радиуса, версия 0.2

В «Настройки → Модификации → AutoLoot» добавлены:
- включение / выключение автолута;
- ползунок радиуса 1–6 метров, шаг 1 метр.

По умолчанию: включено, 3 метра. Настройки читаются каждые 0,1 секунды во время разрешённого игрового взаимодействия. После применения меню изменения действуют без перезапуска игры. Радиус дополнительно ограничен в скрипте диапазоном 1–6 даже при ручном редактировании настроек.

## Установка

Закройте игру. Скопируйте обе папки `Mods` и `bin` из архива в корневую папку The Witcher 3 с заменой файлов этого мода. Оригинальные скрипты игры не заменяются.

Если ваша установка содержит `dx11filelist.txt` и `dx12filelist.txt` в `bin/config/r4game/user_config_matrix/pc`, добавьте в каждый одну строку `modAutoLoot3mRemastered.xml;`, если её ещё нет. Не заменяйте списки целиком. В проверенной здесь установке эти списки отсутствуют: не создавайте их с одной строкой и не удаляйте существующие меню.

Для восстановления исходных значений используйте сброс настроек на странице мода. Сохранение изменений обслуживает штатное меню настроек игры.

## Проверка

Формат TOGGLE, SLIDER и чтение GetVarValue / StringToFloat сверены с файлами установленной Remastered. XML разобран как XML; идентификаторы меню совпадают с идентификаторами чтения в скрипте. Игровая компиляция и отображение меню пока не проверены. Подписи переключателя и радиуса выводятся штатным тегом nonLocalizedName; заголовок страницы задаётся отдельным перехватом построения меню.

Проверить в игре: выключить автолут и подойти к полному сундуку — предметы должны остаться; включить — перенестись. При радиусе 1 м объект на расстоянии 2 м должен оставаться полным, при 6 м — собираться. После перезапуска игры проверить сохранение обоих значений.

Сохраняется штатная передача разрешённых предметов через TakeAllItems и обработка опустошения через OnContainerClosed. Запертые и отключённые контейнеры пропускаются. Равнозначность реакции стражи ручному воровству не проверена.
